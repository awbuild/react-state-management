# Memory Match React Game

An interactive memory card matching game built with React, Context API, and Lorem Picsum images.

---

## Tech Stack

React
React Router DOM
Context API
Vite

---

## API

Lorem Picsum no API key required

---

## Features

Flip and match image cards
Score tracking and leaderboard
High score persistence with localStorage
Multi-screen navigation (Home, Game, Game Over, Leaderboard)

---

## How to Play

1. Click Start Game on the home screen
2. Flip cards to find matching pairs
3. Match all pairs to win
4. Try to beat your high score

---

## How to Run

```bash
npm install
npm run dev
```
